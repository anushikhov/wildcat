Low-Level / Systems Programming Engineering focuses on software that operates close to hardware with minimal abstraction — writing code that directly manages memory, CPU registers, interrupts, device drivers, kernels, bootloaders, compilers, or performance-critical components.    

Often involves manual memory management, concurrency at the hardware level, and assembly or near-assembly languages.   

Key technologies: C, C++, Rust, Assembly, Linux kernel modules, embedded RTOS.   

Common domains: operating systems, embedded/IoT devices, drivers, hypervisors, high-frequency trading systems, game engines (core parts), and security research.
