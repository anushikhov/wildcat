SRE (Site Reliability Engineering) applies software engineering principles to operations problems, with a primary goal of system reliability, availability, scalability, and incident response. SRE teams own production SLOs/SLAs, error budgets, automation of toil, monitoring/observability, and chaos engineering.  

Key technologies: Kubernetes, Prometheus/Grafana, on-call tooling, postmortems, capacity planning.  

Common domains: Large distributed systems (inspired by Google); focuses on "keeping the lights on" while allowing velocity via error budgets. Often overlaps with but is distinct from pure DevOps (culture) or Platform Engineering (DevEx tools).
