Performance Engineering ensures applications meet non-functional requirements for speed, scalability, efficiency, and resource usage throughout the development lifecycle (proactive, not just reactive testing). Involves profiling, bottleneck identification, capacity planning, optimization at code/architecture/infrastructure levels, and performance modeling.   

Key technologies: Profiling tools (perf, flame graphs, YourKit), load testing (Locust, k6), observability (Prometheus, Grafana), algorithmic optimization.  

Common domains: High-traffic web/apps, databases, distributed systems, mobile, gaming, and any latency-sensitive or cost-sensitive (e.g., cloud bills) software.
