Blockchain / Web3 Engineering involves building decentralized, trustless systems using blockchain technology.    

Engineers design and implement smart contracts (self-executing code on the blockchain), decentralized applications (dApps), protocols, tokens, wallets, and infrastructure for Web3 (the decentralized web). 

Emphasis is on immutability, cryptography, consensus mechanisms, and security in trust-minimized environments.   

Key technologies: Solidity (Ethereum/EVM), Rust (Solana, Polkadot), Web3.js/Ethers.js, IPFS, zero-knowledge proofs.  

Common domains: DeFi (decentralized finance), NFTs, DAOs (decentralized autonomous organizations), supply chain transparency, identity, and gaming economies.
