AR/VR Engineering (often grouped under Extended Reality / XR Engineering) focuses on developing immersive, interactive software experiences using augmented reality (AR: overlays digital elements on the real world), virtual reality (VR: fully simulated digital environments), and mixed reality (MR).   

Engineers build applications for headsets, glasses, or mobile devices, handling 3D rendering, spatial computing, gesture/motion tracking, physics simulation, and hardware integration.   

Key technologies: Unity, Unreal Engine, ARKit (Apple), ARCore (Google), C#, C++, computer vision libraries.   

Common domains: gaming, training/simulations, industrial design, education, healthcare (e.g., surgical planning), and enterprise visualization.
