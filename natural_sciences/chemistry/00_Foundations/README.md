# Foundations      
    
## Purpose    
Build the minimum “chemistry operating system” so that Organic/Inorganic/Analytical/Biochem/Materials feel like specializations, not separate worlds.    
    
## Core skills     
- Unit analysis + quick estimates    
- Stoichiometry (moles, limiting reagent, yields)    
- Balance reactions + write net ionic equations    
- Predict shapes/polarity from Lewis/VSEPR    
- Use K/Q and pH/Ka logic without panic    
- Track electrons (oxidation states, basic redox)    
- Read rate laws at a high level (what changes what)    
    
## Map     
1. Units & estimation    
2. Mole + stoichiometry + concentration    
3. Chemical equations & ionic equations    
4. Atomic structure + periodic trends    
5. Bonding + polarity    
6. Lewis/VSEPR/resonance + structure    
7. Intermolecular forces + phases    
8. Thermo intro (ΔH, Hess)    
9. Equilibrium intro (K vs Q, Le Châtelier)    
10. Acids/bases + buffers    
11. Redox intro    
12. Kinetics intro    
13. (Bridge) spectroscopy vocabulary
